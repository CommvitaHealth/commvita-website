# Library — kept, not published

Documents in this folder are part of the commvita explainer library but are
**not** on the public website. Netlify publishes `site/` only, so nothing here
is served.

| Document | Why it is here |
|---|---|
| `commvita-explainer-replacement-model.html` | The replacement-value model: what the estate would cost to buy back, priced line by line, against the cost of running commvita. It carries a full cost model, a per-head licence computation, an FTE plan and named competitor products with contract values. Commercially sensitive; kept for internal and board use. |

`site/_redirects` sends the old public URL to the explainer index, so an old
link does not 404.
