Why this matters

Primary care, community, mental health, social care and the acute trust each run separate systems. The person is scattered across all of them and whole in none.

When systems don’t connect, people carry the data between them — the most costly and error-prone integration layer there is.

Three domains, one record

  • Clinical — the record and the care, across every setting a person passes through
  • Operational — flow, capacity, discharge and the workforce that runs them
  • Governance — incident to board, risk, information governance, AI, audit

Same person, same data, three lenses — so a decision in one is visible in the others.

Key message

Open standards underneath, so the data stays yours. Self-hosted or hosted, configured per jurisdiction, and an export you can check instead of trust.

Editions are additive: start with the part of the problem that hurts, add the rest without re-implementing anything.

What isn’t there

A page of badges would be easier to print than this list, and worth less.

  • No ISO 27001, no Cyber Essentials
  • No Data Security and Protection Toolkit return submitted
  • No certification for the record-sharing standards
  • No independent penetration test or disaster-recovery evidence published
  • openEHR-aligned, not native: it writes to an openEHR repository, ships 0 archetype definitions and has no AQL

None of it is hard to get. It just isn’t done, and a first customer would be right to make it a condition of going live.
